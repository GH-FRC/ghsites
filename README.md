# GH FRC 官网总项目

本目录是 GH FRC 官网的本地总项目空间，用于统一组织网站框架、内部内容、皮肤以及工程日志。

## 目录

- `framework/`：可公开的网站框架代码，不保存 GH FRC 的内部正式媒体资料。
- `content/`：内部内容，包括文字、图片、视频和结构化配置。未来只进入私有 GitHub 仓库。
- `skins/`：可替换皮肤及其设计令牌。本次第一版不制作正式皮肤。
- `engineering-logs/`：所有模块改动的总工程日志。
- `docs/`：跨模块的实施规格与接口说明。

## 当前阶段

当前只搭建桌面端、简体中文、纯黑白的单页网站框架。页面使用明确标注的预留区，不虚构尚未提供的队伍资料。

此项目目前只在本地保存，没有配置 GitHub 远程仓库，也没有部署到正式域名。

## 本地运行

项目固定使用 Node.js 24.14.0。

```bash
npm install
npm run dev
```

本地开发页面默认使用 `http://localhost:4321`。

正式检查命令：

```bash
npm test
npm run check
npm run build
```

构建前脚本会从 `content/` 读取原始媒体，并逐字节复制到被 Git 忽略的临时目录。该目录和最终构建产物都不会进入本地 Git 提交。
