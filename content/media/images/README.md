# Example Images

This folder contains replaceable example images for the public website template. The included `placeholder-logo.png` is `400 × 138 px` and contains no GHFRC or school brand asset.

Before each build, the framework clears its generated content directory and copies only the images explicitly referenced by the selected content configurations into a Git-ignored staging folder.

# 示例图片

本文件夹保存公开网站模板中可替换的示例图片。当前 `placeholder-logo.png` 尺寸为 `400 × 138 px`，不包含 GHFRC 或学校品牌资产。

每次构建前，框架会先清理生成的内容目录，再仅将所选内容配置明确引用的图片复制到被 Git 忽略的暂存目录。
