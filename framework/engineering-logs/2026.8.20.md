# 2026.8.20

## English

### Goals for the Day

- Verify the About FRC framework changes and documentation before publishing the feature to `preview` through a Pull Request.
- Remove outdated single-page assumptions from the framework specification.
- Build a reusable Simplified Chinese and English routing and content-resolution layer without enabling Traditional Chinese output yet.
- Make automatic language selection, manual preference persistence, fallback accessibility, and multilingual search metadata testable.

### Completed Work

- Re-ran the framework tests, Astro check, and static builds with both the public example source and private GHFRC content source successfully.
- Updated the page-form and acceptance rules to cover the independent `/about-frc/` route, cross-page navigation, and context-specific Logo behavior.
- Updated the framework README to describe a long home page with independent pages and removed a duplicated navigation-test entry.
- Confirmed that the framework and private content must be merged in private-content-first order so every Preview build has the required `about-frc.yaml` schema input.
- Added localized home and About FRC routes under `/zh-cn/` and `/en/`, plus no-language and legacy entry pages that preserve the English slug, query string, and page fragment during automatic redirects.
- Added browser-language mapping, safe `localStorage` preference handling that does not persist automatic detection, explicit-URL precedence, and a compact language switcher beside the color-scheme control.
- Centralized deep locale resolution in one module, including blank-value fallback, stable-ID array merging, own-field and stable-ID validation, completeness reporting, fallback-source tracking, optional locale-only media, and complete replacement when a locale changes media type.
- Annotated Chinese fallback titles, content, navigation, Logo alternative text, and ARIA labels with `lang="zh-CN"` on English pages.
- Added self-canonical URLs and matching `zh-CN`, `en`, and `x-default` alternates while omitting the future `zh-Hant` route; incomplete English pages automatically receive `noindex`.
- Added reusable localized image and video content fields and rendering, including language-specific posters and caption tracks, while keeping shared media as the default.
- Updated locale-aware content preparation to clean its staging area, collect the union of referenced media across enabled locales, verify copied files, resolve symbolic links, and reject unsafe or internal-reference paths.
- Added automated coverage for language choice, automatic-versus-explicit persistence, redirect and switch-link preservation, deep fallback and stable-ID validation, locale-specific image and video media, and localized achievement integration; all 78 framework tests and Astro diagnostics passed.
