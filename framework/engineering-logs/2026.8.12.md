# 2026.8.12

## English

### Goals for the Day

- Allow one public framework to run with either replaceable example content or GHFRC's separate private content.
- Prevent a build from mixing files from public and private content sources.

### Completed Work

- Updated framework content loading to prefer an explicitly configured content directory, then the sibling private content repository, and finally the public example content.
- Kept the selected YAML configuration and media files bound to one complete content source.
- Updated media staging to read the Logo path from the selected content configuration instead of requiring one brand-specific filename.
- Updated the implementation specification to distinguish the public placeholder Logo from the unchanged private original.
