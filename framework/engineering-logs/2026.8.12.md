# 2026.8.12

## English

### Goals for the Day

- Allow one public framework to run with either replaceable example content or GHFRC's separate private content.
- Prevent a build from mixing files from public and private content sources.
- Keep the header visible during navigation-triggered scrolling so visitors can select consecutive sections.
- Add an accessible desktop light and dark mode control without coupling it to page content or the future skin implementation.
- Expose a minimal framework seam for the independent achievement module without changing navigation or skin behavior.

### Completed Work

- Updated framework content loading to prefer an explicitly configured content directory, then the sibling private content repository, and finally the public example content.
- Kept the selected YAML configuration and media files bound to one complete content source.
- Updated media staging to read the Logo path from the selected content configuration instead of requiring one brand-specific filename.
- Updated the implementation specification to distinguish the public placeholder Logo from the unchanged private original.
- Distinguished navigation-triggered scrolling from deliberate user scrolling so the header remains available for consecutive section selections.
- Added a DOM behavior test covering downward section navigation while the header was previously hidden.
- Added DOM behavior tests for keyboard and pointer input taking control during navigation-triggered scrolling.
- Added a DOM behavior test for pressing another header section link before the current navigation scroll finishes.
- Added a global color-scheme controller that follows the system setting by default and applies validated manual overrides only for the current browsing session.
- Added a synchronous pre-paint bootstrap in the base layout so a saved session choice is applied before the stylesheet renders.
- Added a `44 × 44 px` sun and moon utility button at the far right of the header with dynamic action labels, keyboard support, focus feedback, and reduced-motion handling.
- Added light and dark semantic design tokens while keeping the transparent Logo readable on its unchanged white backing surface.
- Added nine color-scheme tests covering system preferences, manual switching with session restoration, new-session reset, invalid values, unavailable storage, preference changes, listener cleanup, and the actual pre-paint bootstrap path.
- Consolidated the light and dark design tokens into one `light-dark()` source and made the base layout reuse the tested bootstrap implementation.
- Verified eighteen total tests, zero Astro diagnostics, successful builds with private and public example content, and the rendered desktop control in a real browser.
- Marked the hero and every generated content section with a dedicated achievement-tracking identifier.
- Initialized the independent achievement system through one page-level call without placing achievement rules, persistence, sound, or UI inside the framework.
- Replaced the required achievement package dependency with a framework-owned optional loader so removing the complete module leaves framework installation, tests, checks, and builds operational.
- Added three framework integration tests for the optional module's present, absent, and load-failure states.
- Verified in a clean temporary project copy that removing the complete `achievements/` directory still permits a fresh dependency installation, framework tests, type checks, and a production build with no achievement code in the output.
