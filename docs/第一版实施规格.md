# GHFRC 官网第一版实施规格

## 1. 目标

使用 Astro 与 TypeScript 建立 GHFRC 官网的第一版黑白框架，验证页面结构、内容区域、核心导航交互和简体中文／英文语言基础设施。

本版是后续内容接入与皮肤系统的结构基础，不代表最终视觉设计。

## 2. 页面形式

- 网站以长首页为主体，并允许导航栏目逐步扩展为独立页面。
- 顶部导航不设置“首页”项目。
- 在长首页点击左侧 Logo 返回页面顶部；在独立页面点击 Logo 返回首页。
- “关于 FRC”打开对应语言的独立页面 `/zh-cn/about-frc/` 或 `/en/about-frc/`；其余导航项目目前在对应语言首页平滑滚动到相同栏目，从独立页面点击时先返回对应语言首页再定位栏目。
- 点击导航项目触发页面滚动时，标题栏保持可见，以支持连续选择其他栏目。
- 页面向下滚动时隐藏标题栏；页面向上滚动时恢复标题栏。
- 当前框架已加入手机和 iPad 响应式布局；具体规则以 `responsive-layout-specification.md` 为准。

## 4. 页面内容规则

- 首屏主标题使用 `GHFRC`。
- 首屏介绍文字和媒体使用明确标注的预留区。
- 每个导航项目对应一个首页栏目或独立页面；首页保留相应栏目结构，便于后续逐步扩展。
- 未提供的队伍资料、负责人资料、赛事数据、联系方式和媒体内容全部留空，并使用“内容预留区”标识。
- 不虚构队伍口号、历史、人数、机器人参数、比赛成绩、新闻、赞助商或联系方式。
- 不展示现役成员、历届成员、指导老师、导师或其他个人资料。
- 简体中文文件提供完整基础内容；英文字段或段落缺失时，只为对应字段回退到简体中文，不向访客显示待翻译提示。

## 5. 素材规则

- GHFRC 私有内容仓库保留并使用原始文件 `光华剑桥图标.png` 作为 Logo。
- 公开仓库使用不含 GHFRC 或学校品牌信息的 `400 × 138 px` 中性占位图。
- 原始 Logo 文件不得裁切、调色、压缩、描边、重绘或进行任何其他图片修改。
- 页面只通过 CSS 控制图片在布局中的显示尺寸。

## 6. 模块边界

| 模块 | 本版职责 | 本版禁止事项 |
| --- | --- | --- |
| `framework/` | 页面结构、布局、组件、导航行为、内容接口与黑白基础样式 | 保存内部正式内容或修改原始 Logo |
| `content/` | `config/locales/zh-CN/` 下的完整简体中文基础内容、`config/locales/en/` 下的英文覆盖内容、预留区标签和中性占位图 | 保存 GHFRC 私有媒体、控制页面布局或加入皮肤效果 |
| `skins/` | 预留未来皮肤接口说明 | 制作正式皮肤、粒子效果或皮肤切换器 |
| `achievements/` | 独立成就规则、浏览进度、通知 UI 和声音 | 保存正式内容、修改框架布局或依赖皮肤 |

构建前由总项目脚本读取 `content/` 中的 YAML 与媒体文件，生成框架可消费的临时内容。临时文件不进入 Git 版本记录。私有内容不会被自动发现；只有受信任的构建明确设置 `GH_FRC_CONTENT_DIR` 时，才读取该目录中的完整内容来源。

## 7. 多语言规则

- 当前只生成 `/zh-cn/` 与 `/en/`，两种语言使用相同的英文 slug。
- 无前缀入口优先采用保存在 `localStorage` 中的手动选择；没有有效保存值时，任何中文浏览器语言（包括繁体中文）进入简体中文，所有非中文、空值或无效语言进入英文。
- 浏览器自动判断结果本身不保存为手动偏好；没有手动选择时，重新进入无前缀入口会再次判断浏览器语言。
- 直接访问明确语言 URL 时以 URL 为准，并更新保存值。
- 手动切换语言时保留当前 slug、查询参数和页面片段，选择结果跨浏览器会话长期保存。
- 列表内容按跨语言稳定 `id` 合并；各语言可以覆盖图片和视频，未覆盖时共用简体中文媒体。
- `npm run check:translations` 报告缺少的英文字段但不阻断开发、检查或构建；仍有任一必需英文字段缺失时，生成的英文页面自动设置 `noindex`，所有必需翻译完成后自动恢复可收录状态。
- 未来为香港、澳门和台湾提供统一的 `/zh-hant/`，本版不生成该路径。

## 8. 本版不包含

- 完整的 GHFRC 正式英文内容。
- 统一繁体中文内容与 `/zh-hant/` 页面。
- 皮肤切换。
- 深色与浅色模式切换。
- 正式皮肤、粒子效果和其他装饰动效。
- 正式队伍资料、正式媒体、正式联系方式和个人信息。
- Cookie 同意提示和访问分析。
- GitHub 远程仓库、自动发布、正式域名和托管配置。

## 9. 验收标准

1. 在手机、iPad 和电脑浏览器中能够打开完整的黑白首页和已经实现的独立页面。
2. 顶部导航项目顺序与文字完全符合本规格。
3. 点击“关于 FRC”能够打开对应语言的独立页面；点击其余导航项目能够定位到对应语言首页的相同栏目。
4. 通过导航项目向下定位栏目时，标题栏保持可见并可连续操作。
5. 在首页点击 Logo 能返回页面顶部，在独立页面点击 Logo 能返回首页。
6. 用户主动向下滚动时标题栏隐藏，向上滚动时标题栏恢复。
7. 页面没有虚构尚未提供的正式信息。
8. 框架、示例内容、皮肤和成就系统保存在独立模块中。
9. 私有内容仓库中的原始 Logo 文件与用户提供的源文件保持完全一致，公开仓库不包含该品牌资产。
10. 自动化测试与正式构建均能通过。
11. 首次访问和完整浏览成就均只展示一次，且通知不会脱离配对声音单独出现。
12. `/zh-cn/` 与 `/en/` 使用相同英文 slug；明确语言 URL、自动语言判断和长期保存的手动选择符合本规格。
13. 缺失英文只回退对应简体中文字段，不显示访客提示；翻译报告不阻断构建，仍有任一必需英文字段缺失时生成的英文页面设置 `noindex`。
14. 当前构建不生成 `/zh-hant/` 页面。
