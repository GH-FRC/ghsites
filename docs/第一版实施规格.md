# GHFRC 官网第一版实施规格

## 1. 目标

使用 Astro 与 TypeScript 建立 GHFRC 官网的第一版黑白框架，验证页面结构、内容区域和核心导航交互。

本版是后续内容接入与皮肤系统的结构基础，不代表最终视觉设计。

## 2. 页面形式

- 网站使用一个首页汇总页和 7 个独立主要页面。
- 顶部导航不设置“首页”项目，7 个导航项目分别打开对应的独立页面。
- 点击左侧 Logo 返回首页。
- 首页使用大幅栏目卡片汇总 7 个主要页面，并允许访客进入相应页面了解更多。
- 当前页面在桌面导航与紧凑导航中均显示明确状态。
- 页面向下滚动时隐藏标题栏；页面向上滚动时恢复标题栏。
- 框架适配手机、iPad 和电脑，并支持最低 `320 px` 的页面宽度；具体规则以 `responsive-layout-specification.md` 为准。
- 旧首页 Hash 与 `/about-frc/` 地址自动跳转到对应的新页面。

## 3. 顶部导航

导航项目按照以下顺序排列：

1. 关于 FRC
2. 关于 GHFRC
3. 机器人
4. 赛事成果
5. 新闻动态
6. 赞助商
7. 联系我们

## 4. 页面内容规则

- 首屏主标题使用 `GHFRC`。
- 首屏介绍文字和媒体使用明确标注的预留区。
- 每个导航项目对应一个独立页面，首页使用汇总卡片提供相同入口。
- 未提供的队伍资料、负责人资料、赛事数据、联系方式和媒体内容全部留空，并使用“内容预留区”标识。
- 不虚构队伍口号、历史、人数、机器人参数、比赛成绩、新闻、赞助商或联系方式。
- 不展示现役成员、历届成员、指导老师、导师或其他个人资料。
- 当前生成简体中文、通用繁体中文与英文页面；繁体中文内容必须完整，正式英文尚未填充的字段按既定规则回退到简体中文。

## 5. 素材规则

- GHFRC 私有内容仓库以未修改状态保留并引用原始文件 `光华剑桥图标.png`。
- 公开示例使用不含 GHFRC 或学校品牌信息的 `400 × 138 px` 中性占位图。
- 原始 Logo 文件不得裁切、调色、压缩、描边、重绘或进行任何其他图片修改。
- 页面只通过 CSS 控制图片在布局中的显示尺寸。

## 6. 模块边界

| 模块 | 本版职责 | 本版禁止事项 |
| --- | --- | --- |
| `framework/` | 页面结构、布局、组件、路由、导航行为、响应式规则与内容接口 | 保存内部正式内容、直接绑定具体皮肤或修改原始 Logo |
| `content/` | 可替换的 Markdown 页面、全站 YAML 配置、示例文字、预留区标签和中性占位图；只能选择框架预定义的页面类型 | 保存 GHFRC 私有媒体、自行定义布局规则或加入皮肤效果 |
| `skins/` | 默认黑白皮肤的设计令牌与稳定皮肤入口 | 保存正式内容、修改框架结构或实现尚未确认的正式皮肤切换器 |
| `achievements/` | 独立成就规则、浏览进度、通知 UI 和声音 | 保存正式内容、修改框架布局或依赖皮肤 |

构建前由总项目脚本读取 `content/` 中的 YAML、Markdown 与被明确引用的媒体文件，生成框架可消费的临时内容。临时文件不进入 Git 版本记录；每次切换内容来源前必须清除上一来源的暂存媒体和 Astro 内容缓存。

## 7. 本版不包含

- 完整的正式英文翻译。
- 皮肤切换。
- 正式皮肤、粒子效果和其他装饰动效。
- 尚未提供的正式队伍资料、机器人记录、赛事成果、新闻、赞助商、联系方式和个人信息。
- Cookie 同意提示和访问分析。
- 正式域名和正式环境发布。

## 8. 验收标准

1. 在手机、iPad 和电脑浏览器中能够打开完整的黑白首页和 7 个独立主要页面。
2. 顶部导航项目顺序与文字完全符合本规格。
3. 点击每个导航项目均能打开对应的独立页面，当前页面状态清晰可见。
4. 首页以 7 个汇总栏目提供进入相应页面的入口。
5. 在任意页面点击 Logo 均能返回首页。
6. 用户主动向下滚动时标题栏隐藏，向上滚动时标题栏恢复。
7. 页面没有虚构尚未提供的正式信息。
8. 框架、示例内容、皮肤和成就系统保存在独立模块中。
9. 私有内容仓库中的原始 Logo 文件与用户提供的源文件保持完全一致并用于私有预览；公开仓库不包含该品牌资产，只显示中性占位 Logo。
10. 深色／浅色手动选择只影响当前页面；刷新或打开其他页面后重新跟随系统设置。
11. 公开与私有内容均能通过自动化测试、Astro 检查、静态构建与生成产物验证。
12. 首次访问和完整浏览成就均只展示一次，且通知不会脱离配对声音单独出现。
13. 无前缀入口按浏览器语言或已保存选择进入 `/zh-cn/`、`/zh-hant/` 或 `/en/`，语言切换控件保留当前页面、查询参数和页面片段。
14. 英文翻译未完成时自动回退简体中文并保持 `noindex`；缺失翻译会被报告但不阻断构建。
