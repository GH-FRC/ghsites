# Skins

Skins own the website's visual tokens without changing page content, routes, or the framework's information architecture.

The stable `active.css` entrypoint selects the skin consumed by the framework without requiring a framework edit. It currently loads the `default` skin, which defines the black-and-white framework's color roles, campaign surfaces, sans-serif font category, partner-logo surfaces, and motion timing. Light and dark values are exposed through CSS Custom Properties. Future skins can replace the same approved tokens and visual assets while keeping content and page structure unchanged.

# 皮肤

皮肤负责网站的视觉令牌，不得改变页面内容、路由或框架的信息架构。

稳定入口 `active.css` 负责选择框架使用的皮肤，因此更换皮肤时不需要修改框架。该入口当前加载 `default` 皮肤，其中定义黑白框架的颜色角色、活动视觉表面、无衬线字体分类、合作机构 Logo 展示底色和动效参数。浅色与深色数值均通过 CSS Custom Properties 提供。未来皮肤可以替换同一组获准的令牌和视觉素材，同时保持内容与页面结构不变。
